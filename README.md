# HƯỚNG DẪN TRIỂN KHAI ADMIN PORTAL LÊN GITHUB PAGES

Bạn có thể host trang quản lý bản quyền này **hoàn toàn miễn phí** và bảo mật trên **GitHub Pages**.

---

### CÁCH 1: TẠO REPOSITORY TRÊN GITHUB (KHUYÊN DÙNG)
1. Đăng nhập vào tài khoản [GitHub](https://github.com) của bạn.
2. Tạo một repository mới (ví dụ đặt tên: `viraai-admin-portal`). Chọn chế độ **Public** (hoặc Private nếu có GitHub Pro).
3. Tải file `index.html` trong thư mục `admin-portal` này lên repository đó.
4. Vào mục **Settings** của repository ➔ Chọn mục **Pages** ở thanh menu bên trái.
5. Tại phần **Build and deployment**:
   - **Source**: Chọn `Deploy from a branch`
   - **Branch**: Chọn `main` (hoặc `master`), thư mục `/ (root)` ➔ Bấm **Save**.
6. Sau khoảng 1 phút, GitHub sẽ cung cấp cho bạn đường link website trực tuyến dạng:
   ```
   https://<ten-tai-khoan-github>.github.io/viraai-admin-portal/
   ```
7. Bạn có thể mở link này trên điện thoại hoặc máy tính bất cứ lúc nào để tạo key và quản lý bản quyền!
